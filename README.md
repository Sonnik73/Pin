# Pin 📌

Таск-трекер для Android из экосистемы приложений автора: одноразовые и периодические задачи, дни рождения,
праздники, планы и подарки. Невыполненное переезжает на завтра, задачи хранятся в markdown и синхронизируются
с Google Диском, а выполненное приносит бонусы в Крепости.

- Спецификация и этапы — [docs/SPEC.md](docs/SPEC.md)
- Формат файлов — [docs/FORMAT.md](docs/FORMAT.md)
- Изменения — [changelog/changelog_ru.md](changelog/changelog_ru.md)

APK — в [релизах](../../releases). Сборки подписаны общим ключом экосистемы (как SonnikToPower и Крепость).

## Pin для Windows

В каждом релизе есть установщик `Pin-X.Y.msi` — программа для компьютера (модуль `desktop`, Compose Desktop).
Она читает тот же файл Pin.zip, что телефон хранит на Google Диске:

1. На телефоне: Настройки → «Google Диск — файлом» → «Создать файл на Диске».
2. На компьютере: установить «Google Диск для компьютера» — диск появится в проводнике.
3. В Pin для Windows нажать «Открыть Pin.zip…» и выбрать файл в папке Диска.

Можно начать и без телефона: «Создать новый Pin.zip…» заводит пустой файл. Если он лежит в папке Диска,
телефон потом подключает его через «Подключить существующий файл» — задачи сольются.

Разделы — как в телефоне: «Сегодня», «Календарь», «Планы», «Привычки», «Люди» и «Настройки» с теми же палитрами.
Программа сама перечитывает файл, когда телефон синхронизируется, а свои правки записывает в него же — телефон подхватит их при следующей синхронизации. Установщик не подписан сертификатом Windows,
поэтому при первом запуске SmartScreen может спросить подтверждение («Подробнее» → «Выполнить в любом случае»).
