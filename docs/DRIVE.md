# Google Диск: настройка

Pin синхронизирует папку «Pin» на Google Диске. Нужны сервисы Google Play на телефоне и один раз — проект в Google Cloud.
Это бесплатно, карта не нужна.

1. Открыть https://console.cloud.google.com под своим Google-аккаунтом, создать проект (например, `Pin`).
2. *APIs & Services → Library* → **Google Drive API** → **Enable**.
3. *OAuth consent screen* (*Google Auth Platform*): тип **External**, название `Pin`, своя почта. Режим **Testing**,
   в **Test users** добавить свой аккаунт.
4. *Credentials → Create credentials → OAuth client ID* → **Android**:
   - Package name: `com.sonnik.pin`
   - SHA-1: `3A:ED:4A:D2:91:BF:82:D9:E1:12:0A:9E:2F:B3:E3:C5:56:60:2E:96` (релизный ключ экосистемы; CI печатает его
     в аннотациях каждой сборки)
5. В Pin: *Настройки → Google Диск → Подключить*, выбрать аккаунт, разрешить доступ к файлам, созданным Pin.

## Если что-то не так

- `UNREGISTERED_ON_API_CONSOLE` (код 8) — Google не нашёл Android-клиент с таким пакетом и SHA-1: клиент другого типа
  (Web вместо Android), опечатка в пакете или SHA-1, клиент создан в другом проекте, чем включённый Drive API, или он
  только что создан (начинает работать через 5–30 минут).
- «Google не узнал приложение» (код 10) — пакет или SHA-1 в OAuth-клиенте не совпадают с установленным APK.
- «Нет связи с Google» — нет интернета или Google недоступен; в России консоль и API обычно работают без VPN, но если нет —
  попробовать с VPN.
- В режиме Testing Google может раз в неделю просить войти заново — в настройках появится «Войти заново».
- Pin видит на Диске только файлы, которые создал сам (область `drive.file`). Правка этих файлов на компьютере
  (например, через Google Drive для компьютера и Obsidian) подхватывается; новые файлы, созданные не Pin, — нет.
  Для переноса чужих файлов есть импорт из zip.
