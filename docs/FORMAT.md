# Формат файлов Pin (черновик)

> Черновик. Окончательно формат фиксируется на этапе 0.4 (экспорт/импорт) и не меняется без обратной совместимости.

Папка «Pin» — обычные .md-файлы, которые открываются в Obsidian и правятся руками.

```
Pin/
  tasks/2026-11-05 Купить хлеб.md       одноразовые и периодические задачи
  people/Жена.md                        люди
  birthdays/…  holidays/…  plans/…  gifts/…
  journal/2026-11.md                    журнал событий за месяц
  .pin/settings.md                      настройки, которые стоит синхронизировать
```

Имя файла — для человека; запись опознаётся по `id` в шапке, поэтому файл можно переименовать или перенести в
другую папку.

## Запись

```markdown
---
id: 6f1c2a9e-3b7d-4c55-9f0e-2d8a1b7c4e10
type: one_time
title: Купить хлеб
due: 2026-11-05
original: 2026-11-03
time: "18:30"
priority: normal
tags: [дом, магазин]
rollovers: 2
status: open
created: 2026-11-01T21:05:00+03:00
updated: 2026-11-05T08:12:44+03:00
---
Бородинский, если будет.

- [ ] хлеб
- [x] молоко
```

| Поле | Значение |
|---|---|
| `id` | UUID записи, обязателен; файл без `id` при импорте получает новый |
| `type` | `one_time`, `recurring`, `birthday`, `holiday`, `plan`, `gift` (без учёта регистра) |
| `due` | текущий день, `YYYY-MM-DD` |
| `original` | исходный день; если нет — равен `due` |
| `time` | `HH:MM`, необязательно |
| `priority` | `low` / `normal` / `high` или `0`/`1`/`2` |
| `tags` | список или строка через запятую |
| `rollovers` | счётчик переносов |
| `status` | `open` / `done` / `missed`; для `done` — ещё `completed: <дата-время>` |
| `repeat` | правило повтора (0.2), `person` — ссылка на человека `[[Жена]]` (0.3) |
| `deleted` | `true` — запись удалена (для синхронизации) |
| `created`, `updated` | ISO-8601 со смещением; `updated` решает конфликты |

Тело после шапки — описание в markdown как есть.

## Журнал

```markdown
---
type: journal
month: 2026-11
---
| day | event | id | at | kind | priority | rollovers | on_time |
|---|---|---|---|---|---|---|---|
| 2026-11-03 | ROLLED | 6f1c2a9e-… | 2026-11-04T04:00+03:00 | one_time | 1 | 1 | |
| 2026-11-05 | DONE | 6f1c2a9e-… | 2026-11-05T18:40+03:00 | one_time | 1 | 2 | false |
```

## Правила чтения

- Неизвестные поля сохраняются и не мешают; отсутствующие берут значения по умолчанию.
- Файл, отредактированный вручную, читается, если в нём есть хотя бы заголовок (`title` или первая строка `# …`).
- Битая шапка — файл пропускается, о нём сообщается в итоге импорта.
