# Соглашения проекта Pin 📌

Pin — таск-трекер в экосистеме приложений автора (SonnikToPower, Крепость). `applicationId` — `com.sonnik.pin`.

- Язык интерфейса, документации и сообщений коммитов — русский; идентификаторы в коде — английские.
- Спецификация и этапы — `docs/SPEC.md`; формат .md-файлов — `docs/FORMAT.md`; контракт для Крепости — `docs/CONTRACT.md`.
- Пакет `engine` — чистый Kotlin без Android: перенос, повторы, дни рождения, статистика, разбор и запись .md.
  Покрыт юнит-тестами; даты — через внедрённые `Clock` и часовой пояс, никаких `System.currentTimeMillis()` внутри.
- Дни — логические эпохальные дни (`LocalDate.toEpochDay`) с границей дня из настроек (по умолчанию 04:00, как в Крепости).
- Перенос детерминирован и досчитывается за все пропущенные ночи; исходный день записи сохраняется.
- На телефоне источник истины — Room (offline-first). Удаления — пометкой `deleted` (нужно для синхронизации).
- Чтение .md-файлов и данных других приложений терпит отсутствующие и неизвестные поля.
- Контракт экосистемы — `com/sonnik/ecosystem/contract/EcosystemContract.kt` и `docs/CONTRACT.md` — общий для всех
  репозиториев (Sonnik73/SonnikToPoer, Sonnik73/Garnizon, Sonnik73/Pin): имена менять только синхронно везде.
- Разрешение экосистемы `com.sonnik.ecosystem.permission.READ_DATA` (signature) объявлено в манифесте. Все приложения
  подписаны одним ключом (секреты `SIGNING_*`), SHA-256 сертификата —
  `0f057701a7946499a2b97891744a4ced2ad8f6adaea70494cd5a809e5e6ef650`; CI сверяет его на каждой сборке.
- Разрешение INTERNET — только ради Google Диска (с этапа 0.6) и обновлений с GitHub (проверка с 0.35, выключается в настройках):
  новая версия скачивается APK-файлом в фон (`UpdateChecker.download`) и ставится штатным установщиком Android
  (разрешение REQUEST_INSTALL_PACKAGES), предлагается при входе в приложение. Никакой аналитики и рекламы, лишних библиотек не тянуть.
- Графики рисовать самим на Compose Canvas.
- Ветки: работа идёт в `dev`, в `main` сливаются только готовые этапы — каждый пуш в `main` публикует релиз `vX.Y`.
- При выпуске: поднять `appVersion`/`appVersionCode` в `gradle.properties` и добавить раздел в оба файла `changelog/`.
- Перед пушем: `./gradlew testReleaseUnitTest assembleRelease` или зелёный CI.
